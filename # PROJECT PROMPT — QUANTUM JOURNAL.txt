# PROJECT PROMPT — QUANTUM JOURNAL / PERSONAL TRANSFORMATION APP-

Create a modern, immersive, emotional and highly polished web application in PORTUGUESE (Brazilian Portuguese only) focused on guided personal transformation through 21-day journeys.

The app should feel:
- modern
- spiritual/introspective
- elegant
- cinematic
- emotional
- premium
- calming
- futuristic but human

The visual identity should mix:
- soft glassmorphism
- subtle gradients
- dark immersive backgrounds
- animated transitions
- floating cards
- smooth step-by-step experiences
- ambient particles/light effects
- rounded UI
- emotional onboarding

IMPORTANT:
The application must be FULLY RESPONSIVE:
- mobile
- tablet
- notebook
- ultrawide desktop

The experience on mobile is PRIORITY.

---------------------------------------------------
CORE CONCEPT
---------------------------------------------------

This application is based on a 21-day guided transformation process divided into 3 weeks.

Each week has a psychological focus:

WEEK 1 → OBSERVATION
Focus:
- observing thoughts
- emotional awareness
- identifying patterns
- negative self-talk
- comparison
- automatic behaviors

WEEK 2 → CLEAR PURPOSE
Focus:
- vision
- future identity
- gratitude
- purpose
- emotional alignment
- visualization
- defining a new direction

WEEK 3 → NEW IDENTITY
Focus:
- identity shift
- action
- decision making
- financial consciousness
- sustaining emotional alignment
- becoming the new version of yourself

---------------------------------------------------
APPLICATION FLOW
---------------------------------------------------

The app should work like a guided emotional journey.

The user starts a "Sessão de Transformação".

Each session:
- lasts 21 days
- stores all writings/audio/transcriptions
- can be repeated multiple times
- previous sessions remain saved
- users can compare emotional evolution over time

The user can choose to start:
- from week 1
- from week 2
- from week 3

This means:
- a session can start at day 1
- or directly at day 8
- or directly at day 15

---------------------------------------------------
IMPORTANT RULES
---------------------------------------------------

- Only ONE day can be opened at a time.
- Future days must remain LOCKED.
- The next day only unlocks the next calendar day.
- Users can SEE that future days exist in the timeline, but CANNOT access the content.
- The experience must feel like progressing through a sacred/introspective journey.

Each day should feel:
- immersive
- emotional
- calm
- focused
- guided
